# Standard Operating Procedures & Quality Rules (RAFITACAKE)

## Core Guidelines
1. **Framework & Code Conventions**: Maintain clean, structured, and modular architecture consistent with the project's stack (React + TypeScript on frontend, FastAPI + Pydantic v2 on backend).
2. **Comment Hygiene (antislop-code)**: Comments must be natural, purposeful, and concise. Never use generic AI slop comments (e.g. `// Step 1: Validate`, `// Main logic`, decorative headers `====`). Only explain non-obvious business rules or critical constraints.
3. **Root-Cause Problem Solving**: Always fix bugs at the root cause without introducing regressions or side effects.
4. **Clean Design & No AI Slop**: Retain a polished, intentional aesthetic. Avoid sterile generic AI slop designs.
5. **Interactive & Responsive UI**: Interactive elements must feature smooth hover/active transitions. All interfaces must be fully responsive across mobile, tablet, and desktop screens.
6. **File Organization**: Maintain a clean, organized folder hierarchy. Name files and directories using standard, professional English.
7. **Security & Data Protection**: Protect against data exposure, insecure deserialization, negative financial inputs, and injection vectors.
8. **Permanent Prompt Persistence**: These rules and active skills (`/antislop`, `/antislop-human`, `/antislop-layoutmobile`, `/antislop-code`, `/antislop-copywriting`, `/antislop-ui`) apply permanently across all subsequent tasks even if omitted from the prompt.
